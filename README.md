# AI Email Reply Generator

A beginner-friendly Python CLI application that generates email replies using the OpenAI API and prompt engineering.

## Project Goal

This project aims to explore how Large Language Model (LLM) APIs can be integrated into a Python application to generate email replies in different tones.

## Planned Features

- Accept an email as input.
- Generate replies in professional, friendly, and concise tones.
- Integrate the OpenAI API.
- Handle invalid input and API errors.
- Keep API credentials secure using environment variables.

## Technologies

- Python
- OpenAI API
- Git and GitHub
